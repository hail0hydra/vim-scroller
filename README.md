# vim-scroller


  <br>
  <br>

## Description

- firefox extension for simple movements.

- supported:

```
h - left

j - down

k - up

l - right

G - into the depths of the ocean

gg - fly high into the sky
```

  <br>
  <br>

## Installation

- go to the addons [page here](https://addons.mozilla.org/addon/vim-scroller/) and add it to your firefox!
